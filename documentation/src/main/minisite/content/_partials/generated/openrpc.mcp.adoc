== Methods

=== completion/complete

Parameter structure: either.

Suggests values for a prompt argument or a resource template variable.

Parameters:
* `argument` (object of type `io.yupiik.fusion.mcp.model.CompletionArgument`): The argument being completed and its current value.
* `context` (object of type `io.yupiik.fusion.mcp.model.CompletionContext`): The arguments already resolved.
* `ref` (object of type `io.yupiik.fusion.mcp.model.CompletionRef`): What is completed: a prompt or a resource template.



=== initialize

Parameter structure: either.

Negotiates the protocol version and returns the server capabilities.

Parameters:
* `protocolVersion` (`string`): The protocol version the client wants to use.
* `capabilities` (object of type `io.yupiik.fusion.mcp.model.Capabilities`): What the client supports: roots, sampling, elicitation.
* `clientInfo` (object of type `io.yupiik.fusion.mcp.model.ClientInfo`): Which client is connecting.



=== logging/setLevel

Parameter structure: either.

Sets the minimum severity of the log records sent to the client.

Parameters:
* `level` (`string`): A syslog level name: debug, info, notice, warning, error, critical, alert or emergency.



=== notifications/cancelled

Parameter structure: either.

The client gave up on a request it sent.

Parameters:
* `reason` (`string`): Why the request was cancelled.
* `requestId` (object): The cancelled request id, a string or a number.



=== notifications/initialized

Parameter structure: either.

The client is ready, the session can be used.

Parameters:
* `_meta` (object of type `io.yupiik.fusion.mcp.model.Metadata`)



=== notifications/progress

Parameter structure: either.

Progress of a request the client sent to the server.

Parameters:
* `message` (`string`)
* `progress` (number)
* `progressToken` (object)
* `total` (number)



=== notifications/roots/list_changed

Parameter structure: either.

The client filesystem roots changed.

Parameters:
* `_meta` (object of type `io.yupiik.fusion.mcp.model.Metadata`)



=== ping

Parameter structure: either.

Liveness check, see https://modelcontextprotocol.io/specification/2025-06-18/basic/utilities/ping.

Parameters:
* `_meta` (object of type `io.yupiik.fusion.mcp.model.Metadata`)



=== prompts/get

Parameter structure: either.

Expands a prompt template.

Parameters:
* `name` (`string`): The prompt name, as returned by prompts/list.
* `arguments` (object): The prompt arguments, all strings.



=== prompts/list

Parameter structure: either.

Lists the prompt templates the user can pick.

Parameters:
* `cursor` (`string`): Pagination cursor, unused: all the prompts are returned at once.



=== resources/list

Parameter structure: either.

Lists the resources the client can read.

Parameters:
* `cursor` (`string`): Pagination cursor, unused: all the resources are returned at once.



=== resources/read

Parameter structure: either.

Reads the contents of a resource.

Parameters:
* `uri` (`string`): The resource uri.



=== resources/subscribe

Parameter structure: either.

Asks to be notified when a resource changes.

Parameters:
* `uri` (`string`): The resource uri to watch.



=== resources/templates/list

Parameter structure: either.

Lists the parameterized resources the client can read.

Parameters:
* `cursor` (`string`): Pagination cursor, unused: all the templates are returned at once.



=== resources/unsubscribe

Parameter structure: either.

Stops watching a resource.

Parameters:
* `uri` (`string`): The resource uri to stop watching.



=== tools/call

Parameter structure: either.

Calls a tool.

Parameters:
* `name` (`string`): The tool name, as returned by tools/list.
* `arguments` (object): The tool arguments, they must match its inputSchema.



=== tools/list

Parameter structure: either.

Lists the tools the model can call.

Parameters:
* `cursor` (`string`): Pagination cursor, unused: all the tools are returned at once.
