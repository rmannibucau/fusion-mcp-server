== The short version

[source,bash]
----
mvn package -pl demo exec:exec           # a server on http://localhost:8080/mcp
claude mcp add --transport http demo http://localhost:8080/mcp
----

Add `fusion-mcp-server-impl` to a Fusion application and the three routes come with it:

[options="header",cols="1,3"]
|===
| Route | Purpose
| `POST /mcp` | requests, notifications and responses.
| `GET /mcp` | the server to client event stream.
| `DELETE /mcp` | session termination.
|===

== Checklist before exposing it

* set `fusion.mcp.instructions` - it is what tells the model when to use this server,
* set `fusion.mcp.name`/`title`/`version` so the client shows something meaningful,
* review the tool descriptions with the MCP inspector: they are the interface with the model,
* decide the session policy, `fusion.mcp.requireSession`, and the session timeout,
* behind a load balancer, enable sticky routing on the `Mcp-Session-Id` header,
* put authentication in front of it if the data is not public - MCP has no opinion there, use the regular Fusion
means.
