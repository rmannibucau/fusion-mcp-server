== Methods

=== demo/ask

Parameter structure: either.

Asks the client model to answer a question.

Parameters:
* `question` (`string`): The question to forward to the client model.



=== demo/confirm

Parameter structure: either.

Asks the user to confirm an action.

Parameters:
* `action` (`string`): What has to be confirmed.



=== demo/greet

Parameter structure: either.

Greets someone by name.

Parameters:
* `name` (`string`): Who to greet.
* `times` (integer): How many times to greet, defaults to 1.



=== demo/log

Parameter structure: either.

Sends a log record to the client over the SSE channel.

Parameters:
* `message` (`string`): What to log.



=== demo/prompt

Parameter structure: either.

Demo.

Parameters:
* `code` (`string`): The code to inject in the prompt.



=== demo/roots

Parameter structure: either.

Lists the workspace roots the client exposes.

This method does not have any parameter.


=== demo/search

Parameter structure: either.

Searches the demo catalog.

Parameters:
* `query` (object of type `io.yupiik.fusion.mcp.demo.DemoTools.Query`): The query.
* `tags` (array with items of type `string`): Tags to filter on.
* `options` (object): Extra options.
* `limit` (integer): How many results at most.
* `direction` (enum with potential values `asc`, `desc`): Sort direction.



=== demo/tool

Parameter structure: either.

Demo.

This method does not have any parameter.
